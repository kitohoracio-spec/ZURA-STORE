# ZURA Store 🛍️

Loja de moda moçambicana — construída com React + Vite.

## Funcionalidades
- Catálogo de produtos com filtros por categoria
- Página de produto com encomenda personalizada (medidas, localização, pagamento)
- Carrinho de compras
- Wishlist
- Páginas: Entregas, Devoluções, Tamanhos, FAQ, Sobre Nós, Contacto, Carreiras

## Como correr localmente

```bash
# 1. Instalar dependências
npm install

# 2. Correr em modo desenvolvimento
npm run dev

# 3. Abrir no browser
# http://localhost:5173
```

## Como fazer build para produção

```bash
npm run build
```

## Deploy no Vercel

1. Faz push para o GitHub
2. Vai a vercel.com → "New Project"
3. Importa o repositório
4. Clica Deploy — feito! ✅

## Tecnologias
- React 18
- Vite 5
- CSS-in-JS (inline styles)
